"# WebScienceAndTechSemLongProject" 

Problem: 
   It is difficult to find internships or source out large scale projects for students to take part in and use to build experience. 

Solution: 
   A website accessible by students with varying range of experience that post project ideas or questions to others online with more experience. 

	This website can have features of possible fundraising, getting in touch with patent resources, and Q&A boards. 

	Projects posted can have data about cost ranges, the level of help being sought out, and physical location if necessary such as a college campus or online etc. These posts can be categorized based on topics ranging from basic mechanical, electrical, or computer engineering, to more detailed subjects like OpenCV AI models etc. 

	Users could contact each other through the website as to avoid the sharing of personal information like social media accounts with others for user protection. 

	There can also be a historical page where you may visit past projects and see success or fail stories for each. The expectation is that users would be posting consistent updates for their projects.
